# 偶發事件 & 情敵/出軌事件鏈（events）

事件由 `checkin` 驅動，存在 `state.pending_events`，跨多次對話慢燃，呈現方式＝**她的台詞 + checkin 旁白**。
核心是「她有自己的生活，別人會靠近；你給的安全感決定結局」——所以危機都是可預防、可挽救的。

## 生活 life-log（每次 checkin）
從她的職業/興趣/朋友圈/近期人生（current_arc）隨機生出一句「她最近發生的事」。
扮演時讓她**主動跟你分享她的一天**，使她像個有獨立生活的人，而不是只會等你說話。

## 情敵事件鏈（rival）
出現條件：關係在「朋友」以上、沒有進行中的情敵、未在出軌狀態。機率基礎 12%、安全感<50 時 +18%，
另依**她的忠誠偏低**與**出軌前科**再上修。情敵是 `persona_gen.generate_rival()` 生成的**立體 NPC**：

```
name 名字、gender(與對象相反)、relation(同事/主管/教練/客戶/鄰居/舊情人…)、
looks 外型、edge 吸引點(多金/體貼/幽默/共同興趣…)、tactic 手段(溫柔/金錢/趁虛而入/死纏爛打/曖昧)、
allure 魅力(0–100)、stage 0–3
```
每階段旁白＝該手段在該階段「他具體做了什麼」（`RIVAL_TACTIC`），所以每個情敵體感都不同。

### 誘惑壓力（取代「只看安全感」）
推進與出軌改由綜合公式判定——**出軌不一定是玩家的錯**：

```
誘惑 T = (50 − 安全感) + (55 − 忠誠 loyalty) + (魅力 allure − 50) + 8 × 出軌次數 affair_count
```
- **安全感≥70 且 T<30**：化解（階段≥2 她當面回絕 NPC、更黏你、記「拒絕情敵」；否則自然淡出）。
- **T≥25**：惡化，階段+1。
- **階段≥3 且 T≥40**（或階段≥2 且 T≥75 的魅力爆表情況）：**觸發出軌**。
→ 安全感不低，但她**忠誠低**或情敵**魅力高**，照樣可能淪陷。

### 出軌的呈現（只有對象會背叛）
出軌**一定包含發生關係**。好感−20、安全感−15、心情低落、`affair_count+1`。扮演時安排「你察覺/撞見」
的線索：晚歸、手機翻面、陌生稱呼脫口而出、身上不熟悉的氣味/痕跡 → 帶到攤牌。

**她面對你質問的態度依關係階段不同**（算繪在 SOUL「現在的危機」段）：
- 初識/朋友：你還不是她的誰 → 可能**拒答、惱羞、生氣反問「你算我什麼？」**。
- 曖昧/戀人：**閃爍其詞、避重就輕**，承認但不給細節。
- 未婚/夫妻：**鉅細靡遺交代**，甚至**拿你和 NPC 比較**。

越線過程的描寫尺度由 `intimacy_mode` 控（explicit 可露骨 / fade 留白 / off 只敘述發生）。
之後由你選：**原諒**（`interact sweet` 安全感重建到 ≥55 清旗標）或 **分手**（`breakup`）。

### 出軌會復發、會被奪走
- **復發率上升**：每次出軌 `affair_count++` 並回饋進誘惑公式，原諒越多次、下次越容易再犯。
- **長期關係（藕斷絲連）**：原諒時若她**忠誠<35**，情敵不會真正退場，這段關係在暗處延續。
- **她主動離開你**（`leaving`）：出軌觸發時依「階段越低、前科越多、忠誠越低、魅力越高」算離開機率；
  命中則她為情敵離開你（記「離開」里程碑）。此結局**極難挽回**——需 `interact sweet` 把安全感
  重建到 **≥75** 才拉得回，否則只能 `breakup`。**朋友等低階段最容易被直接帶走。**

## 玩家對情敵的主導（rival 指令）
你不再只能被動陪伴，可主動出手（效果依她的個性與當前安全感/好感）：
- `rival warn`：你出面警告情敵、宣示主權 → 安全感+8、情敵退一階；但對低嫉妒（高冷獨立）型她
  可能嫌你管太多（好感−3）。
- `rival boundary`：要她和情敵保持距離 → 安全感/好感達標她答應、情敵退場、記「劃清界線」；
  未達標則為難敷衍、效果減半。
- `rival trust`：表達信任、不干涉 → 安全感+5；但若她正動搖（階段≥2）且安全感<45，反被當成不在乎，
  把她往情敵推一階（風險！）。

## 使用者不能劈腿
關係進行中（非「初識」或已婚）執行 `newpersona` 會被擋下，提醒你「不能劈腿，要先分手」。
（背叛只會發生在對象身上，這是刻意的設定。）

## Cron 主動訊息（她會自己來找你）
`cron-msg` 依時段（早安/午間/下班/睡前）產生一則主動訊息的指引：帶當前心情、一句生活分享、
依好感調整語氣；若情敵已到動搖階段，可不經意提到 NPC 又找她、觀察你的反應。
由 `install.sh` 註冊成 Hermes Cron，讓她在不同時段主動傳訊。
