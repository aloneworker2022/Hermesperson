# 偶發事件 & 情敵/出軌事件鏈（events）

事件由 `checkin` 驅動，存在 `state.pending_events`，跨多次對話慢燃，呈現方式＝**她的台詞 + checkin 旁白**。
核心是「她有自己的生活，別人會靠近；你給的安全感決定結局」——所以危機都是可預防、可挽救的。

## 生活 life-log（每次 checkin）
從她的職業/興趣/朋友圈/近期人生（current_arc）隨機生出一句「她最近發生的事」。
扮演時讓她**主動跟你分享她的一天**，使她像個有獨立生活的人，而不是只會等你說話。

**鋪墊期情敵會混進來**：若有處於「露臉/接近」期的新面孔，約 40% 機率 life-log 改成
他以**日常人物**身分出現（「聚會他也在」「他幫了我個小忙」）——她隨口提起、毫無曖昧意識，
但留心聽的玩家能**更早無痛察覺**這個人正在靠近。扮演時就讓她自然地當趣事分享，別加戲。

## 情敵事件鏈（rival）
出現條件：關係在「朋友」以上、沒有進行中的情敵、未在出軌狀態。機率基礎 12%、安全感<50 時 +18%，
另依**她的忠誠偏低**與**出軌前科**再上修。情敵是 `persona_gen.generate_rival()` 生成的**立體 NPC**：

```
name 名字、gender(與對象相反)、origin 來源(circle 生活圈／outing 興趣·放假新認識)、
relation 身分(同事/主管/教練/客戶/鄰居… 或 登山同好/旅行同團/課堂同組…)、
looks 外型、edge 吸引點(多金/體貼/幽默/共同興趣…)、tactic 手段(溫柔/金錢/趁虛而入/死纏爛打/曖昧)、
allure 魅力(0–100)、phase 鋪墊期(露臉→接近→追求)、stage 0–3
```

### 他是「慢慢長出來的」，不是憑空冒出的事件（鋪墊期 phase）
會主動靠近她的人，本身就是有興趣了——所以情敵**先以普通人身分出現在她生活裡**，再慢慢變追求者。
新生成的對象一律從 `phase="露臉"` 起步，每次 `checkin` 推進（單一來源 `RIVAL_PHASES`）：

- **露臉**：他常出現在她的生活圈（同事/山友…），**只是普通往來、沒有曖昧**。SOUL 只淡淡提一句
  「最近生活裡常出現一個人」，**不進危機段**。
- **接近**：他開始**主動找她、特別關照**——這是第一個訊號（「他主動靠近就是有意思了」）。SOUL 提示
  「有個人常找我、好像有點在意我，但我還沒往那邊想」，給你**預警**。安全感最多極輕微影響。
- **追求**：正式成為追求者，`stage` 進入 0–3，自此**才**走下面的「誘惑壓力」與出軌判定。

**推進/化解**：你**夠用心（安全感≥65）**→ 鋪墊期就**自然淡出**（露臉期約 50%、接近期約 30%），越早越易
化解；你**冷落（安全感低）/她忠誠低**→ 加速 露臉→接近→追求。**來源**：`circle`（生活圈）約六成、
`outing`（興趣/放假新認識）約四成；她報備純興趣行程時，約 25% 機率「這趟認識了一個人」直接植入一個
`outing`/露臉 的潛在對象（之後走同一條鋪墊鏈）。

> 向後相容：舊存檔的情敵沒有 `phase` → 一律視為已在「追求」期，行為與舊版完全相同。

每階段旁白＝該手段在該階段「他具體做了什麼」（`RIVAL_TACTIC`），所以每個情敵體感都不同。

### 誘惑壓力（取代「只看安全感」）
推進與出軌改由綜合公式判定——**出軌不一定是玩家的錯**：

```
誘惑 T = (50 − 安全感) + (55 − 忠誠 loyalty) + (魅力 allure − 50) + 8 × 出軌次數 affair_count
```
- **安全感≥70 且 T<30**：化解（階段≥2 她當面回絕 NPC、更黏你、記「拒絕情敵」；否則自然淡出）。
- **T≥25**：惡化，階段+1。
- **階段≥3 且 T≥40**（或階段≥2 且 T≥75 的魅力爆表情況）：**觸發出軌**。
→ 安全感不低，但她**忠誠低**或情敵**魅力高**，照樣可能淪陷。

### 追得越久火力越猛（heat 猛攻）——陪伴不再是萬靈丹
追求期每次 `checkin`，情敵累積 `heat`（火力）+1。早期化解依然容易（heat=1 時公式同上），
但**只要他纏上了沒被早早勸退**：
- **誘惑加壓**：`T += 3 ×（heat−1）`——他越追越狠，同樣條件下壓力逐回上升。
- **魅力進化**：`heat≥3` 起每回合 `allure +2`（上限 92）——他越來越會撩。
- **猛攻擋化解**：即使達成化解條件（安全感≥70 且 T<30），有 `min(55%, 15%×(heat−1))` 機率
  被他「不死心、攻勢升級」擋下（旁白【情敵·猛攻】）——**陪得再好也未必一次甩掉他**。
- **趁虛而入**：`heat≥2` 時你又冷落（超過寬限天數沒互動）→ 額外 `T+12`，疊上衰退掉的安全感，
  **一個空檔就可能直接出事**。
扮演重點：猛攻期的他要演得更積極、更精準（記她的喜好、刷存在感）；【情敵·持續】帶
「他越追越猛」時，用旁白給玩家壓力——拖越久越難善了。

### 旁觀者場景（你成了看著他們的第三者；`date` 指令）
她正在和追求者**約會/碰面**，而你撞見了——這一刻視角反轉，你變成旁觀的局外人（NTR 張力核心）。
觸發（旗標 `date_spotted`，兩個入口）：
- **checkin 撞見**：追求期 `stage≥2` 時每次 checkin 約 22% ——你路過咖啡廳/餐廳/河堤…看見他們。
- **報備已讀不回**：她傳了「要跟他出去」的行程告知（`outing_rival`）而你一直沒回——打開時 50% 機率
  **人已經出門了**，你趕到現場只能遠遠看著。
呈現：以**玩家的第三者視角**描寫他們的互動（談笑、距離、肢體語言），她渾然不覺；曖昧程度受
`intimacy_mode` 控（explicit 可寫刺眼的肢體細節／fade 點到為止／off 只寫同桌吃飯聊天）。
然後把選擇交給玩家：
- **`date watch` 默默偷看**：看完全程、她**永遠不會知道**（不寫進她的記憶/里程碑）。看到什麼反映
  動搖深度——投入（機率隨 stage 升）＝動搖加深 stage+1；心不在焉、頻頻看手機＝她惦記的還是你。
  情報只屬於玩家，之後攤牌/裝不知道/加倍對她好都由他。
- **`date interrupt` 上前打斷**：**賭注，不一定有好結果**。成功率吃安全感/好感（stage 3 再 −12%）：
  成功＝她心虛、如夢初醒（安全感+6、情敵退一階、記「當面攔下」）；失敗＝她覺得被跟蹤、當眾難堪，
  反而站到對方那邊（好感−6、怒氣+15、情敵進一階、記「當場鬧僵」）——若這一推讓 stage 到頂 3，
  30% 機率**她賭氣當場挽著他走**（直接觸發出軌鏈）。
- **不出手**：下次 `checkin` 自動「約會散場」——50% 他又前進一步（她隻字不提）、50% 她心虛地
  對你刻意地好。
扮演守則：watch 過的事**她不知道**，她的台詞與記憶不可洩漏「被看見」；只有玩家主動攤牌才算揭露。

### 出軌的呈現（只有對象會背叛）
出軌**一定包含發生關係**。好感−20、安全感−15、心情低落、`affair_count+1`。扮演時安排「你察覺/撞見」
的線索：晚歸、手機翻面、陌生稱呼脫口而出、身上不熟悉的氣味/痕跡 → 帶到攤牌。

**她面對你質問的態度依關係階段不同**（算繪在 SOUL「現在的危機」段）：
- 初識/朋友：你還不是她的誰 → 可能**拒答、惱羞、生氣反問「你算我什麼？」**。
- 曖昧/戀人：**閃爍其詞、避重就輕**，承認但不給細節。
- 未婚/夫妻：**鉅細靡遺交代**，甚至**拿你和 NPC 比較**。

越線過程的描寫尺度由 `intimacy_mode` 控（explicit 可露骨 / fade 留白 / off 只敘述發生）。
之後由你選：**原諒**（`interact sweet` 安全感重建到 ≥55 清旗標）或 **分手**（`breakup`）。

### 撞見現行（變本加厲，夫妻專屬）
**原諒之後變本加厲**：在 **夫妻** 關係、且 **再犯**（`affair_count≥2`）時，出軌觸發有機率（~40%）
變成 `caught_in_act`——你回到家，**當場撞見她正和情敵在自家交媾**，最不堪的正在進行式。
SOUL「現在的危機」段會改演這個場景（畫面尺度受 `intimacy_mode` 控：explicit 可露骨／fade 留白／
off 只點出撞見），被抓包的她無法狡辯，依個性崩潰求原諒／羞憤／破罐破摔。原諒或分手後旗標清除。

### 出軌會復發、會被奪走
- **復發率上升**：每次出軌 `affair_count++` 並回饋進誘惑公式，原諒越多次、下次越容易再犯。
- **長期關係（藕斷絲連）**：原諒時若她**忠誠<35**，情敵不會真正退場，這段關係在暗處延續。
- **她主動離開你**（`leaving`）：出軌觸發時依「階段越低、前科越多、忠誠越低、魅力越高」算離開機率；
  命中則她為情敵離開你（記「離開」里程碑）。此結局**極難挽回**——需 `interact sweet` 把安全感
  重建到 **≥75** 才拉得回，否則只能 `breakup`。**朋友等低階段最容易被直接帶走。**

## 玩家對情敵的主導（rival 指令）
你不再只能被動陪伴，可主動出手（效果依她的個性與當前安全感/好感）：
- `rival warn`：你出面警告情敵、宣示主權 → 安全感+8、情敵退一階；但對低嫉妒（高冷獨立）型她
  可能嫌你管太多（好感−3）。
- `rival boundary`：要她和情敵保持距離 → 安全感/好感達標她答應、情敵退場、記「劃清界線」；
  未達標則為難敷衍、效果減半。
- `rival trust`：表達信任、不干涉 → 安全感+5；但若她正動搖（階段≥2）且安全感<45，反被當成不在乎，
  把她往情敵推一階（風險！）。

## 使用者不能劈腿
關係進行中（非「初識」或已婚）執行 `newpersona` 會被擋下，提醒你「不能劈腿，要先分手」。
（背叛只會發生在對象身上，這是刻意的設定。）

## 主動訊息信箱（她會自己來找你；非同步、不推播）

她趁你不在時傳的訊息會**凍結存進信箱**，不發任何 alert；你下次 `checkin`（打開聊天）才會看到累積的訊息——
就像打開 LINE 看到她稍早傳的話。**呈現時不要報未讀數字**，把它們當作她剛傳、你現在才看到的訊息自然呈現。

**Cron 流程（每次排程觸發跑）：**
1. 跑 `cron-msg`。它會判斷她此刻該不該傳、發第幾則、什麼語氣與主題；睡覺時段預設不傳（`--force` 才演半夢半醒）。
2. 若回的是「不發/還在等/還太近」→ 這次不做事。
3. 若回的是生成指引 → 以她的身分寫出那則訊息，再照指引呼叫 `inbox add "<訊息原文>" --theme <主題>` 存入。

**鬧脾氣升級鏈（綁人物稀有度）：** 第 1 則正常主動；過了「等待時數」仍沒回（你還沒打開）→ 第 2 則
**根據自己上一則自言自語/追問**；最後一則**她就不太高興了**（賭氣、受傷）。上限與等待時數依稀有度遞減——
**越稀有越沒耐性**（N：3 則/等 6h；SSR：2 則/等 2h，第 2 則就生氣）。你打開時若鏈已升到生氣那則，
她的怒氣會上升、心情轉「不安」，要你先 `interact sweet` 哄。打開（checkin）＝已讀＝等同回覆，鏈會重置。

**行程告知（搭訕／外遇／劈腿／NTR 的呈現）：** 主動訊息的「主題」會視情況變成她**主動報備要出門**：
- 沒情敵時＝純興趣/朋友行程（綁她的 hobbies/朋友，唱歌/看展/泡溫泉/回老家過夜…），頂多讓你吃醋。
- 有情敵且動搖（stage≥2）時＝她報備要跟**情敵**出去，隨階段升級：約飯（半遮掩）→ 泡溫泉/喝酒/可能過夜（閃躲愧疚）。
- 出軌後＝坦白/冷淡的去向告知（去他家過夜＝NTR）。
- 接上升級鏈：她報備跟情敵出去、你又沒回 → 賭氣那則會是「算了你都不回，那我真的跟他走了」——把**冷落→被奪走**收成一條線。
- 所有過夜/曖昧暗示**受 `intimacy_mode` 控**：`off` 只陳述去哪、和誰，不帶任何性暗示。

由 `install.sh` 註冊成 Hermes Cron。
